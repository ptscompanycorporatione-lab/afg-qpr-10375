## Čo ťa čaká

Bodky a čiarky. Dva signály, dve slová. Len jedno je pravé.

**CESTA A** — prvý signál:

`-.-/.-../.-/--/.../-/...-/---`

**CESTA B** — druhý signál:

`.--./.-./.-/...-/-../.-`

Odpoveď je jedno slovo. Lúšti sa na [cryptii.com](https://cryptii.com) (morseovka).
